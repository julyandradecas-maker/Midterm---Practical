# Midterm---Practical
This is the practical exam for the second part of the Security Fundamentals course.

In this project, an API was created using FastAPI, allowing a client to create a user account and log in whenever they want. This registration obviously requires a sophisticated level of security; therefore, methods known as "salt" and "pepper" have been implemented. These methods apply an extra layer of security to the hashed passwords, making it difficult for an attacker to obtain them without the "pepper."
